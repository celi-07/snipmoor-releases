# SnipMoor for Windows

A local clipboard library for copied text, screenshots and saved snippets.

[Website](https://snipmoor.whiteeorangee.com) · [Download version 1.0.4 preview](https://github.com/celi-07/snipmoor-releases/releases/tag/v1.0.4)

Version 1.0.4 is a preview. A license is required, and new purchases are currently disabled. The installer has a verified updater signature but no Windows publisher signature. Back up your library and quit the previous app before installing. See the release notes for upgrade details.

This repository contains public download artifacts. Application source remains private. Existing releases and updater verification keys are preserved.
